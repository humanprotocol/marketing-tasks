# Marketing Tasks

Container repository for HUMAN Protocol marketing task projects.

Each project is managed independently and keeps its own dependencies and
`yarn.lock`.

## Services

- `recording-oracle`: Recording Oracle for validating and recording results.
- `exchange-oracle/server`: Exchange Oracle API for collecting submissions.
- `exchange-oracle/client`: Exchange Oracle client for submitting posts.

## Project Commands

Run commands from the project directory you are working on:

```bash
cd recording-oracle
yarn install --immutable
yarn lint
```
